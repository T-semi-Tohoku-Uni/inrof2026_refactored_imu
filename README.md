# inrof2026_imuからの主要な変更点
- 将来的に計測輪機能とimu機能を別々にデバッグできるようにするために、ファイル分割をした
- セカンダリ側のローパスフィルタを追加した(もともと追加されていなかったので)
- DMA転送を採用した
- その他細かな修正等をした

# ファイル階層・役割

- Src
    - main.c
        - 主要なフィルタをかけている
        - ゼロ点補正
        - マドウィックフィルタを用いた姿勢推定
        - CANの送受信
    - imu.c
        - imuのデータ処理部分
        - imuのメモリ読み取り・DMA関連の主要な関数の分離先ファイル
    - data_convert.c
        - uint_to_floatなどの変換関数の分離先ファイル

- Inc
    - macro.h
        - 変更されることを望まないマクロ定義の管理ファイル
